# OpenClaw 方案與選配規格說明指南

> **文件用途：** 本文件提供給內部業務 (Sales) 與成本分析師 (Cost Analysts) 使用，旨在協助設計對外的銷售方案。內容詳列了 OpenClaw 平台目前提供的各種「大腦 (LLM)」與「擴充技能 (Skills)」的選配項目、成本結構及銷售建議。

---

## 一、核心大腦 (LLM) 方案

大腦決定了 Agent 的智商、反應速度以及處理複雜任務的能力。目前平台以 OpenAI 的 ChatGPT 系列模型作為主力。

| 方案等級 | 推薦對象 | 核心模型 | 成本預估 (每 1M Tokens) | 銷售賣點與特色 |
| :--- | :--- | :--- | :--- | :--- |
| **標準版 (Standard)** | 輕量使用者、客服問答、預算有限的客戶 | `gpt-4o-mini` | Input: $0.15<br>Output: $0.60 | **反應極快、C/P 值最高**。<br>適合處理簡單的日常對話、格式轉換或快速查詢。對於一般不需要深度推理的老闆來說已經非常夠用。 |
| **旗艦版 (Pro)** | 重度使用者、需要複雜報告與資料分析的客戶 | `gpt-4o` | Input: $5.00<br>Output: $15.00 | **全能型頂級大腦**。<br>具備極強的邏輯推理、長文檔理解與程式碼/資料分析能力。適合需要 Agent 幫忙看財報、寫企劃書的高階用戶。 |

> **成本控管提醒：** 平台已透過 LiteLLM 導入硬性預算上限功能。業務在銷售時，可採用「包月含 X 美金算力」的形式，超額則自動降速或需額外加購點數。

| 搜尋引擎模組 | 單次搜尋成本 | 模組特性與適用場景 | 業務銷售建議 |
| :--- | :--- | :--- | :--- |
| **Brave Search** (標準配備) | **$0.005** | **基礎聯網能力**。<br>提供純文字的網頁搜尋結果。成本低廉，足以應付日常新聞或簡單名詞查詢。 | 列為所有方案的**免費標配**。由於每月有一定免額，初期可吸收成本作為平台亮點。 |
| **Kimi (Moonshot)** (亞太/中文增強套件) | **約 $0.004**<br>(按 Token 計價) | **中文語境最強、中國在地資訊最準**。<br>非常適合需要搜尋中國市場資料、微信公眾號內容或簡體中文財報的客戶。 | 可包裝成**「大中華區商務情報包」**，適合經常與中國有業務往來的老闆選配。 |

| **Gemini Grounding** (Google 生態套件) | 免費額度大<br>(超過後極貴) | 直接結合 Google 搜尋引擎的結果。 | 作為內部調節成本的備用方案，暫不主動對外主推。 |

## 三、生產力擴充技能 (Productivity Skills)

如同汽車的舒適內裝，這些技能讓 Agent 能直接介入客戶的數位工作流。

### 1. 免費基礎擴充 (標配，無額外 API 成本)
*這些技能執行於本機端，不產生額外 API 費用，可作為吸引客戶的「超值大禮包」。*

*   **PDF 閱讀器 (`nano-pdf`)**：允許 Agent 讀取並分析客戶上傳的 PDF 檔案。
*   **本機系統控制**：如藍牙 (`blucli`)、攝影機 (`camsnap`) 控制 (需視客戶部署環境而定)。
*   **終端機 Email (`himalaya`)**：允許 Agent 代收發 Email (需客戶提供授權密碼)。

### 2. 進階軟體連動 (需客戶自備帳號 BYOA)
*平台不收取代付 API 費用，但可做為「尊榮代管」服務的加值設定費。*

*   **Obsidian 筆記連動**：將 Agent 變成客戶個人知識庫的專屬管家，能搜尋與新增筆記。
*   **1Password 密碼庫連動**：安全的密碼管理整合。

### 3. 高階付費雲端技能 (需依用量計費)
*這些技能會產生外部 API 費用，需計算在客戶的訂閱成本內。*

*   **語音轉文字 (`openai-whisper`)**：
    *   **成本**：$0.006 / 分鐘
    *   **銷售建議**：包裝成**「語音助理套件」**。讓不會打字的老闆可以用語音交代任務。可設定每月贈送 100 分鐘語音額度。
*   **進階地圖與地點資訊 (`goplaces`)**：
    *   **成本**：依 Google Places API 計價。
    *   **銷售建議**：適合需要經常安排行程、查詢餐廳與商務會議地點的客戶。
