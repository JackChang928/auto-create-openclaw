# 基礎設施擴展成本分析：本地多節點 vs 雲端 VPS (以 100 容器為分界)

> **文件用途：** 本文件旨在比較 OpenClaw Agent 平台擴展至 100 個容器（客戶）規模時，「本地自建微型主機叢集 (Local Docker Swarm)」與「雲端虛擬主機 (Cloud VPS)」的成本差異，為技術決策與資金規劃提供量化依據。

---

## 成本分析模型假設

*   **單一 Agent 資源需求估算**：4 vCPU, 8GB RAM (維持 Docker 容器運行與偶發的 Python 資料處理)。
*   **本地機器規格與壽命**：單台主機成本 NT$ 6,000，硬體攤提壽命為 **3 年 (36 個月)**。每台主機運行 1 個 Agent 容器。
*   **雲端計費模型**：採用「標準 VPS / 輕量雲 (月費制)」，以 DigitalOcean/Linode 或阿里雲的標準定價為基準（約 $10 USD/月 = NT$ 320/月，對應 4vCPU/8GB 規格）。
*   **匯率基準**：1 USD = 32 TWD。
*   **電費估算**：微型主機滿載功耗約 15W，每度電(kWh) 以 NT$ 5.0 計算。

---

## 方案 A：本地多電腦部屬 (Local Mini-PC Cluster)
*架構：一台 Master 負責網關與資料庫，100 台 Worker (Mini PC) 透過 Switch 串聯內網，使用 Docker Swarm 分配任務。*

### 1. 資本支出 (CapEx) - 期初一次性投入
*   **Worker 節點 (100台)**：100 x NT$ 6,000 = **NT$ 600,000**
*   **Master 控制節點 (1台高階)**：預估 **NT$ 20,000** (需大容量 SSD 與高 RAM 以應付 Redis, Postgres, LiteLLM)
*   **網路設備 (Switch)**：
    *   2 台 48-port Gigabit Switch (含備援與堆疊)：約 2 x NT$ 15,000 = **NT$ 30,000**
    *   網路線材與機架/層架：預估 **NT$ 10,000**
*   **共享儲存 (NFS Server/NAS)**：確保容器飄移時資料不遺失 (Synology 4Bay + HDD)：**NT$ 40,000**
*   **👉 初期硬體總建置成本 (CapEx)**：**NT$ 700,000**

### 2. 營運支出 (OpEx) - 每月經常性成本
*   **電費 (含 Switch 與 Master)**：
    *   100 台 x 15W = 1.5kW。每月 24h x 30天 = 1080 度。
    *   1080 度 x NT$ 5.0 = **NT$ 5,400 / 月**
*   **頻寬費 (商業光世代)**：1G/600M 固接制網路，預估 **NT$ 2,500 / 月**
*   **場地與空調散熱**：1.5kW 發熱量需小型冷氣常駐，電費預估 **NT$ 2,000 / 月**
*   **👉 每月總營運成本 (OpEx)**：**NT$ 9,900 / 月**

### 3. 本地方案 3 年總成本 (TCO) 攤提表
*   硬體攤提 (36個月)：700,000 / 36 = NT$ 19,444 / 月
*   每月營運：NT$ 9,900 / 月
*   **👉 每月真實成本攤提 (100 個 Agent)**：**NT$ 29,344 / 月**
*   **👉 均攤至單一 Agent 每月基礎設施成本**：**NT$ 293 / 月 / Agent**

---

## 方案 B：雲端虛擬主機部屬 (Cloud VPS)
*架構：向雲端供應商租用大型虛擬機 (例如 8vCPU/16GB 機型)，每台大機器切分運行 8 個 Agent，透過雲端內網 (VPC) 互聯。*

### 1. 營運支出 (OpEx) - 每月經常性成本
*(以 DigitalOcean 共享 CPU 計算，1vCPU/2GB 基準價為 $12 USD)*
*   **100 個 Agent 的算力需求**：約需 100 vCPU / 200GB RAM。
*   **虛擬機租賃成本**：約 100 x $12 USD = $1,200 USD / 月。
*   換算台幣：1200 x 32 = **NT$ 38,400 / 月**
*   **雲端託管資料庫/Redis (Managed Services)**：為確保 Master 節點穩定，使用雲端代管服務：約 $100 USD = **NT$ 3,200 / 月**
*   **網路流量費**：通常 VPS 內含足夠流量，出網流量暫估免額外付費。
*   **👉 每月總營運成本 (OpEx)**：**NT$ 41,600 / 月**

### 2. 雲端方案 3 年總成本 (TCO) 攤提表
*   無期初資本支出 (CapEx = 0)。
*   **👉 每月真實成本攤提 (100 個 Agent)**：**NT$ 41,600 / 月**
*   **👉 均攤至單一 Agent 每月基礎設施成本**：**NT$ 416 / 月 / Agent**

---

## 綜合分析與商業決策建議

### 成本交叉點 (Break-even Point)
*   **本地部屬** 3 年總花費：70 萬 (硬體) + (9,900 x 36) (維運) = **NT$ 1,056,400**
*   **雲端部屬** 3 年總花費：41,600 x 36 = **NT$ 1,497,600**
*   在 **100 個 Agent 滿載運行 3 年** 的情況下，**本地方案可省下約 44 萬台幣 (省 30%)**。

### 決策建議矩陣

| 考量維度 | 方案 A：本地微型主機叢集 (Local) | 方案 B：雲端 VPS (Cloud) |
| :--- | :--- | :--- |
| **初期資金壓力** | **高** (需一次性拿出 70 萬現金) | **極低** (隨收隨付，首月只需 4 萬) |
| **擴展彈性** | **極差** (第 101 個客戶進來時，需等硬體到貨、接線、設定) | **極佳** (一鍵開新機器，5 分鐘上線) |
| **維運難度 (人力成本)** | **極高** (需處理硬體故障、網路線鬆脫、停電、散熱、Switch 當機) | **極低** (硬體故障由雲端原廠負責轉移) |
| **長線利潤率 (滿載時)** | **較高** (單個 Agent 成本降至 $293) | **較低** (單個 Agent 成本死豬價 $416) |

### 💡 執行長 (CEO) 戰略建議
1.  **0 - 50 個客戶階段 (MVP 驗證期)**：**強烈建議使用「雲端方案」**。保留現金流，專注於業務銷售與優化 OpenClaw 軟體功能。不用為了一個月省幾千塊去買一堆電腦堆在辦公室。
2.  **跨越 100 個客戶 (規模化期)**：如果您確定這 100 個客戶會穩定續約，且公司的現金流充裕，此時再將穩定的 Agent 遷移至「本地自建機房」以拉高毛利。
3.  **隱藏的風險：人力成本**。本地方案看似省了 44 萬，但如果三年內需要 MIS 工程師花費超過 44 萬的薪水時間 (約每月 1.2 萬的時間成本) 來排解硬體與區域網路問題，那本地方案實際上是**虧錢**的。
