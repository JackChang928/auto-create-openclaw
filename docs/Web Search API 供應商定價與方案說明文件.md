# Web Search API 供應商定價與方案說明文件

一般而言，聯網搜尋的計費結構包含：**「單次搜尋動作的費用」** + **「模型處理文字的 Token 費用」**。

## 🔍 各供應商詳細特色解析

### 1. Brave Search API (最純粹的搜尋)
* **定位**：純搜尋引擎 API，非直接對話的 LLM。
* **運作方式**：直接回傳網頁結果或 AI 優化過的 Context 讓 Agent 讀取。
* **優勢**：提供每月 $5 的免費額度。若每月搜尋量在 1,000 次以內，基本上可完全免費使用，適合將「搜尋」與「推理」模型脫鉤的開發架構。

### 2. Gemini (Google Search Grounding)
* **定位**：Google 官方的搜尋基礎 (Grounding) 服務。
* **運作方式**：結合 Gemini 模型，直接獲取最新、最即時的 Google 搜尋結果並進行統整。
* **優勢**：**免費額度最大方**。免費層級下每日提供高達 500 次以上的免費額度，對個人開發者或輕量專案極度友善；但超出額度後的單次搜尋定價偏高。

### 3. Grok (xAI)
* **定位**：強調即時資訊與 Agent 工具調用能力。
* **運作方式**：Grok 模型（如 4.1 Fast）在 Tool-calling 上表現優異，可作為自動化 Agent 的底層大腦。
* **優勢**：Token 費用相對便宜，Web Search 呼叫費用公道 ($5/1k)，整體 C/P 值相當不錯。

### 4. Kimi (Moonshot AI)
* **定位**：中文語境最強的長文本與搜尋模型之一。
* **運作方式**：深度結合中國在地資訊與網頁解析。
* **優勢**：搜尋費用明確且低廉（單次約台幣 0.13 元）。若 Agent 的目標任務需要大量閱讀中文網頁或中國在地資料，Kimi 是最佳首選。

### 5. Perplexity API (Sonar)
* **定位**：專為「聯網搜尋與總結」而生的進階平台。
* **運作方式**：結合強大開源/閉源模型與自家精準的搜尋索引，直接回傳高品質的答案。
* **優勢**：**搜尋品質與準確度業界頂尖**，具備深度推理 (Deep Research) 能力。缺點是收費結構複雜（Token + 搜尋請求雙重計費），整體建置成本最高。

---

## 💡 總結與建議

* **追求最低成本 / 個人測試**：優先選擇 **Gemini** (利用每日大額免費度) 或 **Brave Search** (每月 $5 免費)。
* **追求最高回答品質與深度解析**：選擇 **Perplexity**。
* **主打中文/中國市場資料**：選擇 **Kimi**。
* **開發高度依賴 Tool-calling 的自動化 Agent**：選擇 **Grok** 或搭配 **Brave Search** + 任意高智商 LLM。
