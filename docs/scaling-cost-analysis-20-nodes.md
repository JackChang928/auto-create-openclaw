# 基礎設施擴展成本分析：本地多節點 vs 雲端 VPS (20 容器 MVP 階段)

> **文件用途：** 本文件針對 OpenClaw Agent 平台在**初期部署 20 個容器（客戶）**規模時，比較「本地自建微型主機叢集」與「雲端虛擬主機 (VPS)」的成本差異，為初期 MVP 階段的技術決策與資金規劃提供量化依據。

---

## 成本分析模型假設

*   **單一 Agent 資源需求估算**：4 vCPU, 8GB RAM (維持 Docker 容器運行與偶發的 Python 資料處理)。
*   **本地機器規格與壽命**：單台主機成本 NT$ 6,000 (可達 4核心/8G 以上規格)，硬體攤提壽命為 **3 年 (36 個月)**。每台主機運行 1 個 Agent 容器。
*   **雲端計費模型**：採用標準 VPS (如 Linode, DigitalOcean 或 阿里雲)，以 **4 vCPU / 8GB RAM** 作為一個 Agent 的算力基準。*(註：雲端 4C8G 規格之 VPS 月費通常約 $40~$50 USD，此處以保守估算 $40 USD / 月計)*
*   **匯率基準**：1 USD = 32 TWD。
*   **電費估算**：微型主機滿載功耗約 15W，每度電(kWh) 以 NT$ 5.0 計算。

---

## 方案 A：本地多電腦部屬 (Local Mini-PC Cluster - 20 台)
*架構：一台 Master 負責網關與資料庫，20 台 Worker (Mini PC) 透過 Switch 串聯內網，使用 Docker Swarm 分配任務。*

### 1. 資本支出 (CapEx) - 期初一次性投入
*   **Worker 節點 (20台)**：20 x NT$ 6,000 = **NT$ 120,000**
*   **Master 控制節點 (1台高階)**：預估 **NT$ 20,000** (需大容量 SSD 與高 RAM 以應付 Redis, Postgres, LiteLLM)
*   **網路設備 (Switch)**：
    *   1 台 24-port Gigabit Switch：約 **NT$ 5,000**
    *   網路線材與機架/層架：預估 **NT$ 5,000**
*   **共享儲存 (NFS Server/NAS)**：確保容器飄移時資料不遺失 (入門 2Bay + HDD)：**NT$ 15,000**
*   **👉 初期硬體總建置成本 (CapEx)**：**NT$ 165,000**

### 2. 營運支出 (OpEx) - 每月經常性成本
*   **電費 (含 Switch 與 Master)**：
    *   20 台 x 15W = 300W。每月 24h x 30天 = 216 度。
    *   216 度 x NT$ 5.0 = **NT$ 1,080 / 月**
*   **頻寬費 (商業光世代)**：初期 20 個 Agent 流量不高，可使用一般商用頻寬，預估 **NT$ 1,500 / 月**
*   **場地與空調散熱**：300W 發熱量極低，環境空調即可，暫不計入額外專屬冷氣費用。
*   **👉 每月總營運成本 (OpEx)**：**NT$ 2,580 / 月**

### 3. 本地方案 3 年總成本 (TCO) 攤提表
*   硬體攤提 (36個月)：165,000 / 36 = NT$ 4,583 / 月
*   每月營運：NT$ 2,580 / 月
*   **👉 每月真實成本攤提 (20 個 Agent)**：**NT$ 7,163 / 月**
*   **👉 均攤至單一 Agent 每月基礎設施成本**：**NT$ 358 / 月 / Agent**

---

## 方案 B：雲端虛擬主機部屬 (Cloud VPS - 20 個 Agent)
*架構：向雲端供應商租用大型虛擬機或按規格拆分。由於 Agent 需要 4C8G 的強勁算力來跑 Python 與資料處理，我們以滿足總算力需求來計算。*

### 1. 營運支出 (OpEx) - 每月經常性成本
*(以單一 Agent 需要 4vCPU/8GB 資源計算，單價以 $40 USD/月為基準)*
*   **20 個 Agent 的資源需求**：等同於 20 台 4C8G 的 VPS。
*   **虛擬機租賃成本**：20 x $40 USD = $800 USD / 月。
*   換算台幣：800 x 32 = **NT$ 25,600 / 月**
*   **雲端託管資料庫/Redis (Managed Services)**：為確保 Master 節點穩定，使用入門級雲端代管服務：約 $60 USD = **NT$ 1,920 / 月**
*   **👉 每月總營運成本 (OpEx)**：**NT$ 27,520 / 月**

### 2. 雲端方案 3 年總成本 (TCO) 攤提表
*   無期初資本支出 (CapEx = 0)。
*   **👉 每月真實成本攤提 (20 個 Agent)**：**NT$ 27,520 / 月**
*   **👉 均攤至單一 Agent 每月基礎設施成本**：**NT$ 1,376 / 月 / Agent**

---

## 綜合分析與商業決策建議 (MVP 階段)

### 成本交叉點 (Break-even Point)
*   **本地部屬** 3 年總花費：16.5 萬 (硬體) + (2,580 x 36) (維運) = **NT$ 257,880**
*   **雲端部屬** 3 年總花費：27,520 x 36 = **NT$ 990,720**
*   **結論：在 20 個 Agent 皆需要 4C/8G 高算力的情況下，只要營運超過半年（第 7 個月），本地部屬方案的總花費就會低於雲端方案。**

### 決策建議矩陣

| 考量維度 | 方案 A：本地微型主機叢集 (20台) | 方案 B：雲端 VPS (高算力) |
| :--- | :--- | :--- |
| **初期資金壓力** | **中等** (需準備約 16.5 萬台幣) | **極低** (首月只需 2.7 萬) |
| **單位硬體 C/P 值** | **極高** (6000 元買斷 4C8G 算力，雲端要月付 1200) | **極低** (高算力在雲端極為昂貴) |
| **維運難度 (人力成本)** | **中等** (20 台機器尚在單人網管可兼顧的範圍內) | **極低** (硬體故障由雲端原廠負責) |
| **單一 Agent 月成本** | **NT$ 358** (極具價格競爭力) | **NT$ 1,376** (侵蝕利潤) |

### 💡 執行長 (CEO) 戰略建議 (針對高算力需求)

**局勢反轉：由於您的 Agent 需要高達「4 vCPU, 8GB RAM」的算力來執行 Python 等重型任務，雲端的「算力溢價」將會非常恐怖。**
之前 100 台的計算是基於 1C/2G 的輕量級應用，雲端很便宜；但一旦上調到 4C/8G，一台 6000 元的國產 Mini PC 的 C/P 值就會徹底碾壓 AWS 或 Linode。

**強烈建議：初期 20 台直接走「方案 A：本地多電腦部屬 (Local Swarm)」**
1. **回本極快**：16.5 萬的建置成本，對比每個月要付給雲端的 2.7 萬，只要短短 6 個月就能把買電腦的錢完全賺回來。
2. **容錯空間大**：20 台機器的規模，一台普通的 24-port Switch 就能搞定，網路設定簡單，還不需要面臨 100 台時會遇到的機房散熱與複雜路由問題。
3. **高毛利護城河**：將每個客戶的伺服器成本壓在 400 台幣以內，您才能在報價時有更大的讓利空間，或將利潤投入在行銷與客製化開發上。
