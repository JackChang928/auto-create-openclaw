# OpenClaw 擴充技能 (Skills) 成本與設定說明文件

在 OpenClaw 的設定過程中，會出現一個包含數十種 Skills（擴充技能）的列表，並詢問是否要「Install missing skill dependencies (安裝缺少的依賴套件)」。

與 Web Search (聯網搜尋) 大多需要付費 API 不同，**這份列表中的絕大多數技能都是「免費」的**。這些依賴套件通常是本機端的命令列工具 (CLI) 或控制腳本，主要是透過系統套件管理工具（如 `brew`, `apt`, `pip`）安裝在你的電腦上，**不會產生額外的 API 訂閱費用**。

為了方便評估，以下將這些 Skills 依照「成本與授權需求」分為三大類：

---

## 🟢 第一類：完全免費（本機端工具與區域網路控制）

這類工具直接在你的電腦或區域網路內執行，**不需要申請 API Key，也不會產生任何費用**。

* **智慧家庭與硬體控制：**
  * `openhue`：控制區域網路內的 Philips Hue 智慧燈泡（需有實體 Hue Bridge）。
  * `sonoscli`：控制區域網路內的 Sonos 音響系統。
  * `camsnap`：呼叫本機電腦的攝影機進行拍照。
  * `blucli`：管理本機的藍牙設備連線。
* **系統與檔案處理工具：**
  * `nano-pdf`：於本機端處理、讀取 PDF 檔案。
  * `xurl` / `gifgrep` 等：本機端的小型網址處理或檔案搜尋工具。
* **網路通訊：**
  * `himalaya`：終端機版本的 Email 客戶端，輸入現有的信箱 (如 Gmail) 密碼即可收發信件，免收費。

---

## 🟡 第二類：需自備帳號 / 現有軟體連動

這些工具本身不收費，但**需要你已經安裝了對應的軟體，或擁有該服務的帳號**才能授權 OpenClaw 連動。

* `1password`：需安裝 1Password CLI 並擁有訂閱帳號。設定授權後，Agent 可安全地幫你讀取密碼庫。
* `obsidian`：需在電腦上安裝 Obsidian 筆記軟體。設定好你的 Vault（儲存庫）本機路徑後，Agent 就能直接搜尋、讀取或新增你的筆記。
* `gog`：需擁有 GOG (Good Old Games) 平台帳號，可用來讓 Agent 查詢或管理你的遊戲庫。

---

## 🔴 第三類：可能產生費用的雲端 API 服務

少數牽涉到「雲端運算」或「外部商業數據庫」的 Skills，才需要你去註冊開發者帳號、申請 API Key 並按使用量付費：

* `openai-whisper`：如果是串接 OpenAI 的雲端 API 進行語音轉文字，需按分鐘計費（約 $0.006 美金/分鐘）。*註：若你是設定成本機端跑 Local Whisper 模型，則是免費的。*
* `goplaces`：串接 Google Places API 獲取詳細地圖與地點資訊。需綁定 Google Cloud 帳號，但每月通常有 $200 美金的免費額度，個人輕度使用極難超標。
* `summarize`：各類長文摘要工具通常會呼叫外部 LLM（如 OpenAI、Gemini）。這部分的費用取決於你設定讓它呼叫哪一個模型，並依照處理的 Token 數量計費。

---

## 💡 設定建議與總結

1. **安全略過**：在初次設定時，你可以放心地選擇 **"Skip for now"**。OpenClaw 是模組化設計，一開始沒安裝完全不會影響核心系統運作。
2. **按需安裝**：建議只勾選你**「確定知道用途，且平常有在使用的工具」**（例如：你有用 Obsidian 記筆記，就單獨勾選 `obsidian`）。
3. **不用擔心誤扣款**：需要花費的 API 技能，在沒有設定對應的 API Key 之前是無法運作的，所以不用擔心裝了會被默默扣錢。日後需要用到某個技能時，隨時可以再回來單獨安裝並填寫金鑰。
