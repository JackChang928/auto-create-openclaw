# OpenClaw 託管計畫：方案設計指南

> **文件用途：** 旨在幫助您快速理解 OpenClaw Agent 託管計畫的客群定位、內建核心優勢，以及如何透過「選配」與「客製化」模組，為客戶打造專屬的 AI 方案。

---

## 一、OpenClaw Agent 託管計畫與使用對象

本計畫的核心理念是提供 **「開箱即用、尊榮代管」** 的專屬 AI 代理 (Agent) 服務。

### 🎯 目標客群 (Target Audience)
*   **主要對象**：中小企業老闆、高階主管、投資客。
*   **客群特徵**：
    *   **無技術背景**：他們不想去註冊什麼 OpenAI、去懂什麼是 API Key。他們要的是付錢後馬上能用。
    *   **依賴通訊軟體**：日常決策高度依賴飛書 (Feishu) 或微信。
    *   **重視效率與結果**：比起機器人「很會聊天」，他們更在乎機器人能不能「幫他搞定事情」（例如查機票、看報表、找資料）。
*   **業務切入點**：強調「零設定門檻」。客戶只需用飛書掃碼，我們後端全自動部署獨立且私密的 AI 秘書，隨時待命。

## 二、平台「標準配備」(內建預設功能)

每位客戶只要開通服務，其專屬的 OpenClaw Agent 就天生具備以下強大能力，不需額外加購：

1.  **飛書無縫整合 (Feishu Native Integration)**
    *   **作用**：機器人直接入駐客戶的飛書。支援單聊 (1-on-1) 派發私密任務，也支援拉入工作群組 (Group Chat) 協助團隊整理會議記錄。
2.  **自動化記憶管理 (Daily Memory Maintenance)**
    *   **作用**：系統每天凌晨 2:00 自動執行背景任務，整理客戶昨天的偏好與對話，寫入長期記憶 (MEMORY.md)。
3.  **Python-First 資料處理能力 (內建 UV 工作流)**
    *   **作用**：當老闆需要整理表格、清理數據或產出 Office 文件（如 Excel, CSV）時，Agent 預設會寫 Python 程式並使用最新套件來精確執行，而不是用 LLM 瞎掰。

## 三、加值選配工具 (Premium Skills & Tools)

如同買車可以選配音響或天窗，業務可根據客戶需求推薦以下付費模組。

### 1. 聯網搜索工具 (Web Search)
決定秘書收集外部資訊的廣度與精準度。
> **注意**：本平台採「統包代管」，所有客戶共用平台的企業級 API Key。以下為平台承擔之單次調用成本，業務報價時應以「次數包」或「吃到飽」形式包裝，勿讓客戶處理帳號問題。

*   **Brave Search** (平台標配)：提供基礎網頁搜尋。適合找簡單新聞或名詞解釋。*(企業共享成本：$0.005 / 次)*
*   **Gemini CLI / Grounding** (Google 生態)：直接結合 Google 搜尋引擎的結果，對海外英文資訊掌握度極高。*(企業共享成本：$0.014 起 / 次)*
*   **Kimi (大中華情報包)**：中國在地資訊、微信公眾號、簡體中文資料搜尋最強。*(企業共享成本：約 $0.004 / 次)*
*   **Perplexity (深度產研包)**：業界最強的研究型搜尋，回傳深度整理後的報告。*(企業共享成本：$0.005 起 + Token 費 / 次)*

### 2. 知識庫檢索 (RAG / 讀取私有文件)
*   **作用**：讓秘書讀懂公司的 PDF、財報或規章制度，並決定大腦記憶更新的頻率。
*   **選配項目**：
    *   **基礎版 (`nano-pdf`)**：本機即時讀取單個 PDF。只能應付臨時丟給他的單一檔案。*(免費標配)*
    *   **雲端向量檢索 (RAG API)**：將公司所有規章、型錄向量化並隨時檢索。
        *   **成本估算**：採用 OpenAI `text-embedding-3-small` 模型，成本極低 (約 $0.02 / 1M Tokens，可處理約 75 萬字)。
        *   **對記憶管理的影響**：啟用此功能後，秘書可從「每日凌晨彙整一次記憶」升級為**「即時 (Real-time) 寫入與檢索」**，客戶上一秒講過的重點，下一秒就能精準調用，不需等隔天。
    *   **Obsidian 連動 (個人進階版)**：串接客戶現有的知識庫，打造專屬大腦。*(免 API 費，但需收取設定服務費)*

### 3. 多模態能力 (語音與視覺)
針對不愛打字、注重視覺呈現的老闆群體。
*   **語音轉文字 (`openai-whisper`)**：
    *   **作用**：老闆可直接對著飛書發送語音訊息交代複雜任務。
    *   **成本估算**：$0.006 / 分鐘。
*   **文字轉語音 (TTS)**：
    *   **作用**：讓秘書用自然的語音朗讀報告給老闆聽 (如通勤時)。
    *   **成本估算**：依所選 API (如 OpenAI TTS) 計費。
*   **生圖工具 (Image Generation)**：
    *   **DALL-E 3 (`openai-image-gen`)**：自動生成簡報用的示意圖、行銷草圖。*(成本：$0.040 / 張)*
    *   **Nano Banana (`nano-banana`)**：使用 Gemini Imagen 3 API 的輕量級生圖工具，適合快速產生視覺輔助素材。*(成本：$0.030 / 張)*

### 4. 差旅與地圖助理
*   **Google Places (`goplaces`)**：
    *   **作用**：精準查詢海外餐廳評價、商務會議地點或導航規劃。
    *   **成本估算**：$0.017 ~ $0.032 / 次。
    *   ⚠️ **區域限制注意**：OpenClaw 預設使用 Google 圖資，**在中國大陸地區查詢極不準確且缺乏圖資**。
*   **高德地圖 (Amap) / 百度地圖 (客製串接)**：
    *   **作用**：若客戶主要活動範圍在中國大陸 (如深圳)，需強烈建議捨棄 Google，改由開發團隊**專案客製串接**國內地圖 API，方能確保地圖搜尋與導航功能正常運作。

## 四、訂製化功能 (在地化專屬場景 - 深圳客群)

針對深圳與大灣區的商務客群，標準的海外 API (如 Google) 往往不夠接地氣。業務可主打「深度客製化開發」，將 Agent 打造為具備在地行動力的超級助理。

以下功能需要額外專案報價，並由開發團隊介接中國國內服務的 API：

1.  **商旅訂票小幫手 (攜程/同程 API)**
    *   老闆一句話：「幫我查下週二早上去上海高鐵還有沒有商務座」，秘書即時調用國內票務 API 列出班次與價格。
2.  **商務宴請與訂餐 (大眾點評/美團 API)**
    *   場景：「今晚在福田區幫我找一家安靜適合談生意的高檔粵菜，要有包廂。」秘書能根據真實評分篩選並提供連結。
3.  **企業信用調查 (企查查/天眼查 API)**
    *   場景：「查一下這家供應商有沒有法律訴訟風險。」對老闆來說是極具價值的避險工具。
4.  **國內物流追蹤 (順豐/快遞100 API)**
    *   自動追蹤重要文件的收發狀態，主動在飛書回報「您的合約已於今早被客戶簽收」。

> **業務策略提示**：訂製化功能是拉高客單價的關鍵。請向客戶強調，這不是一個只會聊天的聊天機器人，而是能真正與國內商業生態對接的「數位員工」。
