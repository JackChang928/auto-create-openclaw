
## T3 備份腳本設計思考（2026-04-10 02:22）

### 核心挑戰：Docker Volume 備份

Docker Named Volume 不能直接 `cp`，只能用 `docker run` 臨時容器掛載後打包。

**設計選擇：**
```
docker run --rm \
  -v "${VOL_NAME}:/data:ro" \
  -v "${DEST_DIR}:/backup:rw" \
  alpine \
  tar czf "/backup/${FNAME}.tar.gz" -C /data .
```

### 為何用 Alpine 而非直接 tar？

- Alpine 極輕量（~5MB），避免汙染主機
- `:ro` 掛載確保只讀安全
- `docker run` 隔離性佳，不依賴主機 tar 版本

### 空 Volume 處理

一開始遇到問題：如果 volume 為空，`tar` 仍會產生有效（但為空）的 archive。
→ 加入 `find` 預檢查：無任何檔案時 skip，並回傳 0（不算錯誤）

### 支援多前綴

docker-compose 專案名可能影響 volume 前綴：
- `auto-create-openclaw_litellm_pgdata`（已處理）
- 可能前綴變化，寫了迴圈嘗試

### User Instances 打包

`data/instances/` 為空（尚无用戶 workspace），但腳本已完整支援：
- `tar czf` 保留相對路徑
- 排除 `.cache`, `node_modules`, `__pycache__` 等

### 保留策略：4 份

每週一次備份，4 份 = 一個月，災難還原足夠。

**完整 inspect vs 精簡摘要？**

- `_config.json`：完整配置（還原核心）
- `_env.sh`：環境變數（經脫敏，開放查閱）
- `_ports.txt`：端口映射（網路規劃用）
- `_mounts.txt`：掛載點（路徑還原用）

### 差異備份策略設計
核心問題：如何在沒有 Rsync 的情況下實現增量備份？

**方案：Manifest-based 差異追蹤**

1. **下次完整備份**執行後，自動建立 `.diff-manifest.json`，內容：
   ```json
   {
     "scan_epoch": 1744226400,
     "configs": {
       "litellm/litellm_config.yaml": {"mtime": 1744226000, "hash": "abc123..."}
     },
     "volumes": {
       "auto-create-openclaw_litellm_pgdata": {"updated": "2026-04-10T03:25:00Z"}
     },
     "containers": {
       "litellm-proxy": {"config_hash": "def456..."}
     }
   }
   ```

2. **差異備份**執行時：
   - 重新掃描當前狀態 → `.current-state-TIMESTAMP.tmp`
   - Python3 比對兩個 JSON：hash / UpdatedAt / config_hash
   - 只備份有差異的項目

3. **差異清理**：每類差異保留 7 份（比完整備份 4 份更積極，因為差異檔案通常很小）

### 技術細節
- **configs 比對**：SHA256 hash（比 mtime 更可靠，避免touch 時間重置的問題）
- **volumes 比對**：Docker UpdatedAt 時間戳（Docker 內部維護，無法被人為篡改）
- **containers 比對**：`docker inspect` 完整 config.json 的 SHA256
- **db**：始終備份（SQLite 很小，每天備份合理）
- **images**：跳過（每次 `docker pull` image ID 都會變，差異無意義）

### 整合至 backup-all.sh
```bash
./backup-all.sh          # 完整備份
./backup-all.sh --diff   # 差異備份（相對於上次完整備份）
```

### Bug 修復記錄
1. `wc -l` 在無檔案時返回多行 `0` → 用 `find ... | wc -l` 配合 `count=${count:-0}` + `count=$(( count + 0 ))`
2. `set -u` + `DIFF_RESULT=$(compute_diff ...)`：當 compute_diff 無輸出時 DIFF_RESULT 為空但未設定 → 移除 DIFF_RESULT 變數，改用管線處理
3. `log` 函式 `tee -a` 輸出到 stdout 污染命令替換捕獲 → 改為 `>&2` stderr
