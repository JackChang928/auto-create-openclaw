**任務**: 實現 `/health` 路由（包含 model availability）

**變更內容**:

   - 返回 `{ models, statusCode, error }`，`models` 為模型名稱陣列

**結論**: T7 通過。`/api/health` 路由已實現，包含 model availability。

### T8 實現 ✅

**任務**: 實現 `/spend` 路由（用戶維度的花費查詢）

**變更內容**:

1. **provisioner.js** - 新增 `getLiteLLMSpend(userId)` 函數:
   - 調用 `GET ${LITELLM_PROXY_URL}/spend?user_id=<userId>`
   - 使用 `LITELLM_MASTER_KEY` Bearer Token 認證
   - 返回 `{ totalSpend, statusCode, error, details }`

2. **server.js** - 新增 `/api/spend` 端點 (T8):
   - Query 參數：`user_id`（必填，對應 litellm 的 user_id，即 agent_id）
   - 調用 `getLiteLLMSpend(user_id)` 獲取花費
   - 返回 `{ user_id, totalSpend, statusCode, timestamp }`
   - 使用 `requireAdmin` 中間件

3. **server.js** - 更新 import 引入 `getLiteLLMSpend`

**驗證方式**: `GET /api/spend?user_id=<agent_id>` with admin auth should return:
```json
{
  "user_id": "agent_xxx",
  "totalSpend": 0.05,
  "statusCode": 200,
  "timestamp": "..."
}
```

**結論**: T8 通過。`/api/spend` 路由已實現。
