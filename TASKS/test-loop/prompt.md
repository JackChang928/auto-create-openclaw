# Task: 驗證持續迭代循環能正常運作

## 目標
每次執行，在 `TASKS/test-loop/LOOP.md` 追加一筆記錄，格式：
```
### [時間戳] Round N
- 上次嘗試：...
- 本次行動：...
- 結果：成功/失敗
- 下次方向：...
```

## 步驟
1. 讀取 `LOOP.md` 找到目前的 Round 數
2. 如果失敗，讀取「下次方向」繼續執行
3. 執行完畢後更新 `LOOP.md`
4. 附注：如果發現 LOOP.md 不存在，初始化並從 Round 1 開始

## 重要
- 每次只推進一點
- 失敗了也要記錄原因，給出「下次建議嘗試的方法」
- 不要急於一次完成，追求可持續的迭代
